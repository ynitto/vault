### 要約
ZOZOTOWNのカート決済画面リプレイスに伴い発生した膨大なテスト工数と、コードベースの自動テストによる属人化を解消するため、Claude CodeとPlaywright CLIを組み合わせた自然言語によるE2E自動テストシステムを構築した事例です。

### 要点
- **課題背景**
    - リプレイスと既存機能の二重開発によりテストケースが爆発的に増加。
    - 複雑な計算ロジックを含むため、手動検証のコストが限界に達していた。
- **解決策：AIエージェント駆動テスト**
    - **自然言語テスト:** Confluenceに記述した手順をAIが解釈し実行。
    - **AI自律操作:** Playwright CLIのスナップショット機能を活用し、CSSセレクタ不要でUI変更に強い自動操作を実現。
    - **計算検証の自動化:** システムから独立した計算サービス（TypeScript）を構築し、AIがテスト計画時に期待値を算出して照合。
- **運用の工夫**
    - **ユーザー承認フロー:** AIの実行計画を事前にユーザーが確認・承認することで、意図の齟齬を防止。
    - **自己拡張型リファレンス:** 未定義の操作手順はAIが自ら作成して蓄積する仕組みを導入。
    - **ツール自作:** 必要なCLIツール（atlassian-cli, zozo-sql-server-cli）自体もClaude Codeで開発。
- **導入効果**
    - 人手による計算確認が不要となり、PC・SPの同時並列実行でテスト時間を大幅短縮。
    - 開発者が他業務を並行させながら、正確性の高い網羅的なテストが可能に。
