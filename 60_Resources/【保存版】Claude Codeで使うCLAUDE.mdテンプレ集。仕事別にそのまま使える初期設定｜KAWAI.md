### 要約
Claude Codeの効率的な運用のために、作業ルールや禁止事項を記した「`CLAUDE.md`」の活用方法と、職種・タスク別のテンプレートをまとめた記事です。

### ポイント
- **CLAUDE.mdの役割**
    - プロジェクトのMemory（作業ルール・制約・ワークフロー）を保存する場所。
    - 毎回同じ指示をする手間を省くために使用する。
- **主な構成要素**
    - 共通の「作業ルール」「出力ルール」「安全ルール」「保存先」「報告形式」を定義する。
- **活用すべきシーン別テンプレート**
    - **note記事作成:** 文体・構成の指定、抽象論の回避。
    - **議事録整理:** 正確性重視、決定事項・TODOの分類。
    - **リサーチ:** 事実と解釈の明確な区分け。
    - **開発:** 変更前確認と既存ルールの遵守。
    - **事業企画:** 目的・顧客の明確化を優先する手順の固定。
- **運用のコツ**
    - 最初は薄く保つことが重要。
    - 「毎回言い直していること」を徐々に追加して成長させる。
    - 特定作業の手順は「skills」ディレクトリに切り分けるのが推奨。
